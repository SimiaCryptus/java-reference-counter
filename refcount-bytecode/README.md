# refcount-bytecode

ASM-based JVM bytecode analysis and verification module for reference-counted compiled classes, JAR archives, and non-Java JVM modules (Kotlin, Scala, Groovy, and generated bytecode).

## Overview

While [`:refcount-autocoder`](../refcount-autocoder/README.md) analyzes and rewrites `.java` source files via Eclipse JDT, `:refcount-bytecode` operates directly on compiled JVM `.class` files and `.jar` archives using ObjectWeb ASM (`org.ow2.asm`). This enables static reference-counting verification of:

- **Non-Java JVM modules** — Kotlin (`compileKotlin`), Scala (`compileScala`), Groovy (`compileGroovy`), and mixed-language Gradle source sets
- **Precompiled binaries and third-party/upstream JARs** — modules where `.java` source files are unavailable
- **Post-compilation / instrumented outputs** — verifying that compiled bytecode preserves reference ownership invariants

- **Gradle Plugin ID:** `com.simiacryptus.refcount-bytecode`
- **Plugin Class:** `com.simiacryptus.ref.bytecode.RefCountBytecodePlugin`
- **CLI Entry Point:** `com.simiacryptus.ref.bytecode.BytecodeVerifier`
- **Task Group:** `refcount`

## Gradle Plugin Configuration

```kotlin
plugins {
    java // or kotlin("jvm"), scala, groovy
    id("com.simiacryptus.refcount-bytecode") version "2.1.0"
}

refcountBytecode {
    includeTests.set(true)            // Include test source-set class outputs
    failOnError.set(true)             // Fail the Gradle build when verification errors are found
    strictBlindParameters.set(true)   // Flag ref-counted values passed to non-@RefAware Object parameters
    logException.set(true)            // Log detailed failure summary to stderr
    force.set(false)                  // Execute even if refcount-core is not detected in project dependencies
    excludePackages.set(listOf())     // Package prefixes to exclude from analysis
    excludeClasses.set(listOf())      // Fully qualified class names to exclude
    // targetFiles.from(file("libs/external-module.jar")) // Optional additional .jar or .class directories
}
```

Boolean extension properties also support JVM system property overrides (`-DincludeTests`, `-DfailOnError`, `-DstrictBlindParameters`, `-DlogException`, `-Dforce`).

## Gradle Tasks

| Task | Task Class | Description |
|---|---|---|
| `refcountBytecodeVerify` | `BytecodeVerifyTask` | Runs full hierarchy, field-lifecycle, closure, and intra-procedural data-flow verification across compiled `SourceSet` outputs (Java, Kotlin, Scala, Groovy) and configured `targetFiles` |
| `refcountBytecodeCheck` | `BytecodeCheckTask` | Runs fast structural, type-hierarchy, `@MustCall`, and `@RefAware` override checks on compiled classes |
| `refcountBytecodeReport` | `BytecodeReportTask` | Generates human-readable (`build/reports/refcount-bytecode/report.txt`) and JSON (`build/reports/refcount-bytecode/report.json`) analysis reports |

## Verification Rules (`RuleId`)

### Hierarchy & Contract Verification (`HierarchyVerifier`)
- **`NON_STATIC_INNER_REFCOUNTED`** — Non-static inner class implements `ReferenceCounting` without `@RefIgnore`
- **`UNACCOUNTABLE_REF_FIELD`** — Non-reference-counted class declares non-static reference-counted fields
- **`MISSING_FREE_METHOD`** — Concrete `ReferenceCountingBase` subclass with reference-counted fields omits `_free()`
- **`MISSING_MUST_CALL_SUPER`** — Method overriding a `@MustCall` method (such as `_free()`) fails to invoke `super`
- **`MISSING_REF_AWARE_OVERRIDE`** — Method override drops `@RefAware` present on a super-declaration parameter

### Field Lifecycle Verification (`FieldLifecycleVerifier`)
- **`FIELD_NOT_FREED_IN_FREE`** — Reference-counted instance field is not released in `_free()`
- **`FIELD_OVERWRITTEN_WITHOUT_FREE`** — Live reference-counted field is overwritten without freeing its previous reference (supports both free-before-write and Kotlin/Java swap-then-free `val old = this.f; this.f = next; old?.freeRef()`)
- **`FIELD_FREED_OUTSIDE_FREE`** — Instance field is freed in a non-`_free()` method without nulling or reassigning the field

### Intra-Procedural CFG & Stack/Local Data-Flow Verification (`MethodDataflowVerifier`)
- **`UNFREED_REFERENCE`** — Owned parameter, allocation, or returned reference is not freed or transferred before `return` / uncaught `throw`
- **`DISCARDED_REFERENCE`** — Owned allocation or method return value is immediately popped or lost in a chained call
- **`DOUBLE_FREE`** — Reference is freed or consumed more than once
- **`USE_AFTER_FREE`** — Reference is dereferenced, invoked, or passed after being freed or consumed
- **`UNOWNED_REFERENCE_CONSUMED`** — Borrowed reference (`this`, un-incremented field read, `@RefIgnore` parameter, or closure capture) is freed, stored, or returned without `addRef()`
- **`BRANCH_CONSUMPTION_MISMATCH`** — Reference is consumed on one control-flow branch while remaining live on another (with path-sensitive `IFNULL` / `IFNONNULL` refinement for Java null guards and Kotlin `?.` safe calls)
- **`BLIND_PARAMETER_PASS`** — Reference-counted value is passed to an untyped / non-`@RefAware` parameter (e.g., `java.util.List.add(Object)` instead of `RefList.add(@RefAware T)`)
- **`RETURN_LOSES_REF_AWARENESS`** — Owned reference is returned as a non-`ReferenceCounting` type without `@RefAware`
- **`UNSAFE_CLOSURE_CAPTURE`** — Non-reference-counted closure captures and leaks reference-counted state

## Non-Java JVM Language Support

`:refcount-bytecode` detects and handles compiler idioms across JVM languages:

- **Kotlin (`SourceLanguage.KOTLIN`):** Detects `@kotlin.Metadata` and `.kt`/`.kts` debug attributes, recognizes `kotlin.jvm.internal.Intrinsics` (`checkNotNull*`, `areEqual`) and `TypeIntrinsics`, supports safe-call `?.freeRef()` / `?.addRef()` bytecode sequences, swap-and-free property setters, `kotlin.jvm.internal.Lambda` closures, and skips compiler-generated `$default` bitmask stubs, covariant bridges, and `$WhenMappings` classes.
- **Scala (`SourceLanguage.SCALA`):** Detects `@scala.reflect.ScalaSignature` and `.scala` sources, recognizes `BoxesRunTime` intrinsics, and verifies `$anonfun$` closure methods and `AbstractFunction*` implementations.
- **Groovy (`SourceLanguage.GROOVY`):** Detects `groovy.lang.GroovyObject` implementations and skips synthetic `$getCallSiteArray` helpers.
- **Compiled / Debug-Stripped Bytecode (`SourceLanguage.BYTECODE`):** Gracefully falls back to class/descriptor names and synthetic slot identifiers when `SourceFile` or `LocalVariableTable` attributes are absent.

## Standalone CLI & Programmatic Usage

### Command Line

```bash
java -cp <refcount-bytecode-classpath> com.simiacryptus.ref.bytecode.BytecodeVerifier \
    --classpath <dep1.jar:dep2.jar> \
    --report build/reports/refcount.json \
    build/classes/kotlin/main build/classes/java/main
```

### Java / Kotlin API

```java
BytecodeVerifier verifier = new BytecodeVerifier(
    VerifierConfig.builder()
        .strictBlindParameters(true)
        .build()
);

VerificationResult result = verifier.analyze(
    List.of(new File("build/classes/kotlin/main")),
    List.of(new File("libs/refcount-core-2.1.0.jar"))
);
result.throwIfErrors(); // Throws BytecodeVerificationException if any ERROR diagnostics exist
```
